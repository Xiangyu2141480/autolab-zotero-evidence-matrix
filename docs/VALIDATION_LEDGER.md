# 7-Day Validation Ledger

Start this ledger only after approval for public visibility and controlled outreach. Use participant codes, never names or contact details. Do not attach a source CSV or copied research content.

## Definitions

- **Qualified user:** an adult researcher, student, librarian, or systematic-review practitioner who self-identifies as using Zotero or a comparable citation manager and voluntarily agrees to test only the synthetic example or their own permitted local data.
- **Independent successful run:** a qualified user, without live operator help, completes all four README Quickstart commands in a clean local environment and opens a nonempty Markdown output. A screenshot is not required and should not be requested.
- **Reuse:** the same coded participant independently repeats a conversion on a separate session or states that they completed a second permitted local conversion. It is counted once per participant.
- **Countable feedback:** a completed response to the template with permission to count it. Do not infer success from a download, star, view, or reply.

## Targets and stopping rule

- Day 7 minimum: 3 independent successful runs and 1 reuse.
- Day 30 directional target: 10 successful runs, 3 reuses, and 2 explicit paid-intent signals.
- Stop/pivot at day 7 if the minimum is not met, if users cannot complete the first run without a product change, or if feedback indicates that a local CSV transformation is not the needed workflow. Do not add features before reviewing this evidence.

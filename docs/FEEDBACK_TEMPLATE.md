# Voluntary Feedback Template

Use only after separate approval for controlled outreach. Do not request a name, email address, institution, raw CSV, paper text, screenshots containing research material, or any health/patient information.

1. Did you complete one local CSV-to-Markdown conversion? `Yes / No`
2. If no, at which numbered Quickstart step did you stop? `1 / 2 / 3 / 4 / Other`
3. Did the Markdown output help you compare notes by topic? `Yes / Partly / No`
4. Would you use the same workflow again for another note export? `Yes / No / Unsure`
5. What single change would reduce friction? `Free text, no source content`
6. Optional: May this anonymous response be counted in the validation ledger? `Yes / No`

Record only the coded outcome in `docs/VALIDATION_LEDGER.md`; do not store the response text unless the participant explicitly consents and it contains no restricted content.

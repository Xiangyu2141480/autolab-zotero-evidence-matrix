# 60-Second Demo Script

This is a script, not a recording. Use the synthetic example only.

| Time | Show | Say |
|---|---|---|
| 0–10s | `examples/notes.csv` | “This is a local CSV of paper notes. The sample is synthetic; your files stay on your computer.” |
| 10–25s | Run the four Quickstart commands in the README. | “The tool reads one CSV and writes one Markdown file; it does not connect to Zotero or any online service.” |
| 25–45s | Open `evidence-matrix.md`. | “Rows are grouped by topic, and every claim keeps its cite key so the source remains traceable.” |
| 45–55s | Point to the Synthesis table. | “The goal is a faster first-pass evidence matrix, not automated research interpretation.” |
| 55–60s | Show the validation/error note in README. | “Invalid input is rejected clearly; no account, upload, or payment is involved.” |

Stop if a demonstrator tries to open a real research CSV during a public demo.
